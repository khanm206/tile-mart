# 🧱 TileMart

A modern and responsive tile shop web application built with secure authentication, user profile management, and a clean user experience. TileMart allows users to explore products, manage their accounts, and interact with a visually appealing interface optimized for all devices.

---

## 🌐 Live Website

🔗[ https://tile-mart.vercel.app](https://tile-mart-two.vercel.app)

---

## 📖 Project Overview

TileMart is a full-stack web application designed to simulate a modern tile marketplace experience. The project focuses on secure user authentication, protected routes, profile management, responsive UI design, and smooth user interaction.

The application is built using modern technologies including React, Next.js, MongoDB, Tailwind CSS, and Better Auth.

---

# ✨ Key Features

## 🔐 Authentication & Authorization

- User registration with email and password
- Secure login system
- Google social login authentication
- Authentication and authorization handled using Better Auth
- Private/protected routes for authenticated users only
- Persistent session management

---

## 👤 User Profile Management

- Users can view their profile information
- Users can update their personal data
- User data securely stored in MongoDB
- Dynamic profile update functionality

---

## 🎨 Modern UI/UX

- Fully responsive design for mobile, tablet, and desktop
- Clean and modern interface
- Interactive components and smooth layout
- Attractive product presentation

## ⚡ Additional Functionalities

# 🔒 Authentication Workflow

1. User registers or logs in
2. Better Auth verifies authentication
3. User session is securely maintained
4. MongoDB stores user information
5. Protected pages are accessible only to logged-in users
